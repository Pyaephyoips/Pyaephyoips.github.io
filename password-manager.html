Local-only, zero-knowledge tool. Your vault is encrypted in your browser with AES-256-GCM before it ever touches disk, and it is stored only in this browser's local storage — nothing is sent to any server. There is no password recovery: if you forget your master password, the vault cannot be decrypted by anyone, including the site owner. This is an open-source educational project, not an audited security product — for real-world sensitive credentials, consider a maintained, independently audited password manager.

Unsupported browser

This tool needs the Web Crypto API (crypto.subtle), which requires a modern browser and a secure (HTTPS) context. Please try a recent version of Chrome, Firefox, Edge, or Safari.
